# ROS-RTEMS

ROS-RTEMS 是一个面向机器人应用的实时系统移植与集成工程。

> 工程初始化中 —— 源码将陆续添加，请关注本仓库更新。

## 项目简介

本工程旨在将 ROS（Robot Operating System）与 RTEMS（Real-Time Executive for
Multiprocessor Systems，实时多处理器操作系统）进行集成，探索在硬实时约束下
运行机器人应用的可能性。
